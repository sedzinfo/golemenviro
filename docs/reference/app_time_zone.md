# The time zone of the app

The one
[`pimoroni()`](https://sedzinfo.github.io/golemenviro/reference/pimoroni.md)
sets while the app runs, for the axis titles of the hours.

## Usage

``` r
app_time_zone()
```

## Value

The name of the time zone, such as "Europe/Bucharest".

## Examples

``` r
app_time_zone()
#> [1] "Europe/Athens"
```
