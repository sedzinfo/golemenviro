# Steps of one blue, from light to dark

The color scale of the daily pattern. In dark mode it runs the other
way, so that low values fade into the dark page and high values stand
out, as they do on a light page.

## Usage

``` r
blue_steps
```

## Format

A character vector of 5 hexadecimal colors.

## Examples

``` r
blue_steps
#> [1] "#cde2fb" "#86b6ef" "#3987e5" "#1c5cab" "#0d366b"
```
