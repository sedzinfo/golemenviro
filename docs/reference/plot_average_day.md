# A typical day of one sensor

For each hour of the day, the median of the hourly averages over all the
days (the line), and the middle half of the days, between the 25th and
75th percentiles (the band): a narrow band means that hour is much the
same every day.

## Usage

``` r
plot_average_day(hourly, variable, unit = "", mode = "light")
```

## Arguments

- hourly:

  Data frame from
  [`get_hourly()`](https://sedzinfo.github.io/golemenviro/reference/get_hourly.md).

- variable:

  Name of the sensor, for the title and the hover labels.

- unit:

  Unit of the readings, `""` for none.

- mode:

  `"light"` or `"dark"`, the mode of the app.

## Value

A plotly object.

plot_average_day(hourly, "Temperature", "C")
