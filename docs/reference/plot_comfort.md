# Comfort zone: temperature against humidity

A point for every hour, at its average temperature and humidity, colored
by the hour of the day (night blue, morning orange, midday yellow,
evening red), over a shaded box for the comfortable ranges. The title
says how many of the hours were inside the box, and the corners name
what lies that way: warm and dry, warm and humid, cool and dry, cool and
humid.

## Usage

``` r
plot_comfort(
  temperature,
  humidity,
  mode = "light",
  temperature_range = c(20, 25),
  humidity_range = c(40, 60)
)
```

## Arguments

- temperature, humidity:

  Data frames from
  [`get_hourly()`](https://sedzinfo.github.io/golemenviro/reference/get_hourly.md)
  of temperature and humidity.

- mode:

  `"light"` or `"dark"`, the mode of the app.

- temperature_range, humidity_range:

  The comfortable ranges, the same as the green bands of the Current
  tab: 20 to 25 degrees Celsius and 40 to 60%.

## Value

A plotly object.
