# Bars of the daily averages of a particle sensor

One bar per day, with the guideline of the World Health Organization for
the average of a day as a dashed line, so the days above it stand out.
The axis starts at 0 and always reaches above the guideline.

## Usage

``` r
plot_daily_means(daily, variable, guideline, mode = "light")
```

## Arguments

- daily:

  Data frame from
  [`get_daily()`](https://sedzinfo.github.io/golemenviro/reference/get_daily.md).

- variable:

  Name of the sensor, for the title and the hover labels.

- guideline:

  The guideline for the average of a day.

- mode:

  `"light"` or `"dark"`, the mode of the app.

## Value

A plotly object.
