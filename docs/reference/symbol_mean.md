# Greek mu and sigma, degrees Celsius, and micrograms per cubic metre

Written as code points, as the R code of a package has to stay ASCII.

## Usage

``` r
symbol_mean

symbol_sd

degrees_celsius

micrograms_m3
```

## Format

Character strings.

## Examples

``` r
paste0("22 ", degrees_celsius, ", ", symbol_mean, " = 12 ", micrograms_m3)
#> [1] "22 °C, μ = 12 µg/m³"
```
